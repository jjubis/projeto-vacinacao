# Imuniza+

Sistema local de gestão de vacinação com cadastro de cidadãos, postos, vacinas, estoque, agendamentos e histórico vacinal.

## Início rápido

```powershell
npm install
npm start
```

Crie antes um arquivo `.env` com `SESSION_SECRET` e, opcionalmente, `PORT`. A aplicação fica disponível em `http://localhost:3000` por padrão.
